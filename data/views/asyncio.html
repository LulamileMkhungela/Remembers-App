Cancelling a task

A task can be cancelled by calling Task.cancel(). This arranges for a CancelledError to be thrown into the wrapped coroutine on the next cycle of the event loop.

async def worker():
    try:
        await asyncio.sleep(10)
    finally:
        # always runs, including on cancellation
        await close_connection()
Never swallow CancelledError. Raising anything other than CancelledError from a task that was cancelled will be treated as a failure of the task, and cleanup that awaits inside finally can itself be cancelled.

Shielding from cancellation

If a coroutine must not be interrupted, wrap it in asyncio.shield(). The inner task keeps running when the outer await is cancelled, and the outer caller sees CancelledError once the shielded work is awaited again.

await asyncio.shield(flush_writes())

Use this sparingly. A shielded coroutine that never finishes is a shutdown that never finishes.

Task groups

A task group is an async context manager that keeps a group of tasks alive and cancels the others if any one of them raises.

async with asyncio.TaskGroup() as tg:
    tg.create_task(handle(a))
    tg.create_task(handle(b))

If a child raises an exception other than CancelledError, the remaining tasks in the group are cancelled and the group re-raises an ExceptionGroup once all of them have finished.

Cancelled vs raised

  • task.cancelled() is True only when the task was cancelled and did not suppress it.
  • A task that finished by raising an exception is not cancelled — check task.exception().
  • Calling task.exception() on a cancelled task raises CancelledError.
